# GD&T Engineer v5.1

Komplet React/Vite-app med den opdaterede True Position Calculator.

## Nyt i v5.1
- Separat størrelsesvisualisering med minimum, nominel, maksimum og faktisk featurediameter
- Faktisk featurecirkel skifter til rød, når størrelsen ligger uden for tolerancen
- Positionvisualisering viser tilladt centerzone, faktisk featurecirkel og målt center
- Separat status for dimension og position

## Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Appen er beslutningsstøtte og ikke en formel standardvalidering.
